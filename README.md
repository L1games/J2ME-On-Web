# J2ME Online Mode
Use this mode if you want to use the localmensin tool and depend on CheerpJ servers.

# Notes:
- This mode is not compatible with Python.
- You can use "npx http-server" as indicated above.
- In this case, If you have already run "npx http-server", open it in your browser: "localhost:8080".
  
# In Node.js:
If you have Node.js installed on your PC, simply run:
```bash
npx http-server
```
